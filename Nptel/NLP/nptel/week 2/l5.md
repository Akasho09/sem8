# 🔹 1. Goal of Evaluation
- 👉 A good language model should:
Assign high probability to real sentences
Assign low probability to incorrect sentences

## 🔹 2. Evaluation Setup
- 📌 Standard Approach
Train on training data
Evaluate on test data
Compare models

## 🔹 3. Types of Evaluation
1. Extrinsic Evaluation
👉 Task-based evaluation
- Examples:
Spelling correction

Machine translation
- ✔ Choose model with best task performance

2. Intrinsic Evaluation
👉 Direct model evaluation
- ✔ Uses:
👉 Perplexity

## 🔹 4. Perplexity (CORE CONCEPT)
- For sequence:
w1, w2, ..., wn
- Perplexity:
PP = P(w1...wn)^(-1/n)
- 🔹 Using Chain Rule
PP = (∏ P(wi | context))^(-1/n)
- 🎯 Interpretation
Low PP → Good model
High PP → Poor model
- 📊 Example (Lecture)
| Model   | Perplexity |
| ------- | ---------- |
| Unigram | 962        |
| Bigram  | 170        |
| Trigram | 109        |

- 🔹 Meaning
962 → model confused among ~962 choices
109 → much better prediction

## 🔹 5. Intuition Example
If:
P(word) = 1/10
- Then:
PP = 10
- 👉 Model chooses among 10 options

## 🔹 7. Major Problem: Data Sparsity
- Possible n-grams → huge
Observed → very few
- ⚠️ Issue
Unseen n-grams:
P = 0
- 👉 Sentence probability = 0 ❌

## 🔹 8. Solution: Smoothing
👉 Assign small probability to unseen events

- 🔹 Concept
Reduce probability of seen words
Redistribute to unseen words

## 🔹 9. Laplace Smoothing (Add-1)
- 📌 Formula
```yml
P(wi | wi-1) =
(Count(wi-1, wi) + 1) /
(Count(wi-1) + V)
```
- 🔹 Effect
Zero counts → non-zero
Frequent words → reduced

## 🔹 10. Add-k Smoothing
- 📌 General Form
P = (Count + k) / (Count + kV)
- 🔹 Special Case
k = 1 → Laplace

## 🔹 11. Effective Counts
- After smoothing:
High counts ↓ decrease
Zero counts → small positive
- 📌 Example Insight
“I want” → reduced
“I to” → gets small probability

## 🔹 12. Unigram Prior Smoothing
- Add-1 treats all unseen words equally ❌
✔ Better Idea
- Use:
👉 Word frequency
- 🔹 Insight
Common words → higher probability
Rare words → lower probability

## 🔹 13. Why Better?
👉 Uses real corpus statistics
👉 More realistic distribution

## 🔹 14. Key Takeaways
Perplexity = main intrinsic metric
Lower perplexity = better model
Data sparsity = major challenge
Smoothing solves zero probability problem
Add-1 = simple but not optimal
Unigram prior = improved approach
