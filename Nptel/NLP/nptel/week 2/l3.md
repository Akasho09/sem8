# 🔹 1. Big Picture
- We now move from:
Edit Distance (Week 2 L1, L2)
- 👉 To:
Probabilistic Spelling Correction

## 🔹 2. Core Idea: Noisy Channel Model
- User intends to type a correct word →
- But passes through a noisy channel →
- Produces a misspelled word
- 🔹 Representation
Correct word → w
Observed (incorrect) word → x

- 🎯 Goal
Find:
Best w such that P(w | x) is maximum

## 🔹 3. Using Bayes’ Theorem
We cannot directly compute:
- P(w | x)
So we use:
- P(w | x) = (P(x | w) × P(w)) / P(x)
- 🔹 Simplification
Since P(x) is constant:
argmax P(w | x) = argmax P(x | w) × P(w)

## 🔹 4. Meaning of Terms
1. P(x | w) → Error Model
Probability of typing x instead of w
- 👉 Depends on:
Insertions
Deletions
Substitutions
Transpositions

## 🔹 2. P(w) → Language Model
Probability of word w occurring
- 👉 Depends on:
Frequency in corpus

## 🔹 5. Candidate Generation
Before applying model:
👉 Generate possible words
- 🔹 Methods
Edit distance ≤ 1 or 2
Similar pronunciation
- 📊 Key Insight (from lecture ):
~80% errors → distance 1
Almost all → distance ≤ 2

## 6. Example: “acress”
Possible candidates:
actress, access, across, caress, cress, acres
- 🔹 Types of Edits
Candidate	Operation
actress	deletion
cress	insertion
caress	transposition
access	substitution

## 🔹 7. Computing P(x | w)
- We calculate probabilities using corpus statistics
- 🔹 Types
1. Deletion
xy → x

2. Insertion
x → xy

3. Substitution
x → y

4. Transposition
xy → yx
- 🔹 How probabilities are computed?
- 👉 Need two corpora:
Original (with errors)
Corrected version

- 🔹 Example (Deletion)
P(delete y after x) =
(count of xy → x errors) / (count of xy in corpus)

## 🔹 8. Computing P(w)
- More frequent words → higher probability
- 🔹 Example
"the" → high probability
rare word → low probability

## 🔹 9. Final Selection
Compute:
> P(x | w) × P(w)
👉 Choose maximum
- 🔹 Observation
Sometimes two words have similar probability
- Example:
actress vs across
- 👉 Need context

## 10. Context-Based Correction
versatile acress whose
- Candidates:
actress
across
- 🔹 Compare:
versatile actress whose ✅
versatile across whose ❌
- 🔹 How?
- Use:
👉 Bigram probabilities
- Example:
P(actress | whose) > P(across | whose)

## 🔹 11. Real-Word Errors
- Word is correct spelling but wrong context
- 🔹 Examples
"be" instead of "by"
"three" instead of "there"
"two" vs "too"
- ⚠️ Problem
Cannot detect using dictionary

## 12. Solution Strategy
For each word:
Generate candidates
Include original word
Evaluate full sentence probability

## 🔹 13. Sentence-Level Model
- Given sentence:
w1, w2, w3, ..., wn

- We want:
argmax P(W | X)

## 🔹 14. Challenge
- If each word has k candidates:
👉 Total sequences:
k^n (exponential)

## 🔹 15. Optimization Assumption
From lecture :
👉 Assume:
At most ONE error per sentence

## 🔹 Benefit
- Instead of:
k^n
- We get:
O(n × k)

## 🔹 16. Computing P(x | w) for Sentences
- Assume independence:
P(x | w) = ∏ P(x_i | w_i)
- 🔹 Cases
If word unchanged:
P(w_i | w_i) = high (e.g., 0.9 or 0.99)
- If error:
Use edit probability

## 17. Computing P(w) (Language Model)
- Probability of word sequence
- 🔹 Methods
Unigram model
Bigram model
Trigram model
- 👉 This is called:
Language Modeling (next topic)

## 🔹 18. Final Formula
Best sentence = argmax P(x | w) × P(w)

## 19. Key Takeaways
Noisy channel = core NLP model
Combines:
Error model
Language model
Context improves accuracy
Real-word errors need full sentence analysis
