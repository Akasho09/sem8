## Symmetric vs Asymmetric Cryptography
| Feature   | Symmetric Cryptography  | Asymmetric Cryptography       |
| --------- | ----------------------- | ----------------------------- |
| Keys Used | Same key                | Public + Private key          |
| Speed     | Faster                  | Slower                        |
| Security  | Less secure key sharing | More secure                   |
| Usage     | Encryption              | Encryption, Digital Signature |
| Example   | AES, DES                | RSA, ECC                      |

## Euler’s Totient Function
- Denoted by: ϕ(n)
    - Counts positive integers less than n that are coprime to n
- For primes:
    > ϕ(pq)=(p−1)(q−1)
- Used in RSA key generation.

- Modular Inverse
- For:a−1modm
- Condition:
> a×a^−1≡1(modm)
Used to calculate private key in RSA.
