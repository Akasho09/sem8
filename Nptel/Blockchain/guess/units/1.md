## Hash Functions
- A hash function is a:
    - Mathematical algorithm that converts input data of any size into a fixed-size output called a hash value, digest, or hash code.
- Used heavily in:
    Blockchain
    Cryptography
    Digital signatures
    Password storage
    Data integrity verification
- Types of Hash Functions
| Hash Function | Output Size |
| ------------- | ----------- |
| MD5           | 128 bits    |
| SHA-1         | 160 bits    |
| SHA-256       | 256 bits    |
| SHA-512       | 512 bits    |
