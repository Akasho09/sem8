# Blockchain Elements - IV

## 🌐 1. Joining a Bitcoin Network
- Bitcoin is a peer-to-peer (P2P) network
- No central server
- How a node joins:
    - Install Bitcoin client
    - Connect to known nodes (seed nodes)
    - Download blockchain data
    - Become part of network
- Key Points:
    - Each node:
    - Maintains full/partial blockchain
    - Verifies transactions
    - New node syncs with existing network
- Result:
    - 👉 Node becomes independent participant

## 📡 2. Transaction Flooding
- When a transaction is created → it is broadcast to entire network
- Process:
    - User creates transaction
    - Sent to nearby nodes
    - Nodes verify transaction
    - Forward to other nodes
- Flow:
    - Transaction → Node → Neighbor Nodes → Entire Network
- Key Idea:
    - Called “flooding” because:
    - Message spreads rapidly
    - Like a ripple in water
- Purpose:
    - Ensure all nodes know about transaction
    - Maintain consistency

## ⛏️ 3. Block Mining
- Process of creating a new block
- Steps:
    - Collect valid transactions
    - Form block
    - Solve Proof of Work (PoW)
    - Find valid nonce
- Condition:
    - Hash(Block Header) < Target
- Outcome:
- First miner to solve:
    - Adds block
    - Gets reward
- Key Points:
- Requires high computation
- Based on trial-and-error

## 📦 4. Block Propagation
- Once a block is mined → it is broadcast to network
- Process:
    - Miner creates block
    - Sends to neighboring nodes
    - Nodes verify block
    - Forward further
- Flow:
    - Miner → Nodes → Entire Network
- Result:
    - All nodes update blockchain
    - Maintain synchronization
- Important:
    - Nodes reject invalid blocks

## 🔀 5. Forking & Longest Chain Rule
1. Forking Occurs when:
    - Two miners create blocks at same time
- Result:
    - Chain splits into two branches
- Temporary Situation:
    - Some nodes follow chain A
    - Others follow chain B
2. 🧠 Resolution: Longest Chain Rule
- 👉 Nodes accept:
    - Chain with highest cumulative work
- Process:
    - Both chains grow
    - One becomes longer
    - Network switches to longer chain
- Outcome:
    - Shorter chain discarded
    - Its blocks become orphan blocks
- Key Insight:
    - “Longest” = Most computational work, not just length
- ⚠️ Why Important?
    - Prevents double spending
    - Maintains consensus
