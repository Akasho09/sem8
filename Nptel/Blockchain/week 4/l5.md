## 🔁 6. Transaction Handling in Fork
- Problem:
    - Forked block may contain valid transactions
- Solution:
    - Identify uncommitted transactions
    - Return them to:
    - Unconfirmed transaction pool
- Example:
    - Tx1 → already in main chain ✔️
    - Tx2 → not included ❌ → re-added

## ⏳ 7. Eventual Consensus & Finality
- Concept:
    - Consensus is not immediate
- Achieved over time
- Rule (Bitcoin):
    - Transaction confirmed after 6 blocks
- Meaning:
    - If block survives 6 confirmations → final

## 🛡️ 9. Security & Attacks in PoW

1. 🔴 (A) Sybil Attack
- Attacker creates multiple fake identities
- Goal:
    - Control network
    - Spread false data
- Solution:
    - Restrict peer connections
    - IP-based diversification

2. 🔴 (B) Denial of Service (DoS)
- Flood node with:
    - Fake transactions
    - Heavy data
- Effect:
    - Slows system
    - Consumes resources
- Solution:
    - Limit connections / disconnect attacker

## ⚠️ 10. Monopoly Problem
- Powerful miners dominate network
- Reason:
    - More computing power → higher success rate
- Result:
    - Rich miners → More rewards → More power
- Effect:
    - Centralization risk
    - Unfair system

## 📉 11. Reward Reduction Effect
- Mining reward decreases over time
- Small miners leave network
- Outcome:
    - Few large miners remain
    - Leads to monopoly

## 📊 12. Limitation of Proof of Work
❌ High Energy Consumption
❌ Slow Transactions
❌ Fork Issues
❌ Centralization Risk
❌ Vulnerable to 51% attack
