## 🪙 1. Generation of Bitcoins (Mining)
- Bitcoins are created during mining
- How?
- When a miner successfully creates a block:
- Gets block reward
- Gets transaction fees
- Example:
- Current block reward ≈ 6.25 BTC
- Earlier:
- Block 0 → 50 BTC
- Key Idea:
        - Mining = Block creation + Bitcoin generation


## 📉 2. Block Reward Reduction (Halving)
- Reward reduces every 210,000 blocks (~4 years)
- Pattern:
| Year              | Reward   |
| ----------------- | -------- |
| Initial           | 50 BTC   |
| After 1st halving | 25 BTC   |
| Then              | 12.5 BTC |
| Now               | 6.25 BTC |
- Future:
    - Will reduce further (≈ 3.125 BTC next)
    - Last Bitcoin mined ≈ year 2140
- Purpose:
    - Control supply
    - Prevent inflation

## ⚙️ 3. Difficulty Adjustment
- Faster computers → faster mining
- Solution:
    - Increase difficulty
- How?
    - Adjust every 2016 blocks (~2 weeks)
- Mechanism:
    - More power → Increase difficulty → Maintain ~10 min/block
- Difficulty Meaning:
    - More leading zeros required in hash

## 💸 4. Transaction Fees
- Users pay fees to miners
- Why?
    - To include transaction in block
- Unit:
    - Satoshis per byte
- Total Miner Reward:
    - Total Reward = Block Reward + Transaction Fees

## ⚠️ 5. Double Spending Problem
- Problem:
    - Same bitcoin used twice
- Example:
    - Alice sends same BTC to Bob & Tom
- Why difficult in digital?
    - No physical transfer
- Solution in Bitcoin:
1. Transaction Validation
Nodes verify all transactions

2. Blockchain Recording
Only one valid transaction accepted

3. Longest Chain Rule
Only valid chain survives

4. Confirmations
Transaction accepted after:
Multiple blocks added after it

- Important:
    - Block reward given after ~100 confirmations

## 🔐 6. Bitcoin Anonymity
- Users are not directly identifiable
- Why?
- Uses:
    - Public keys
    - Hash of public keys
- Additional Privacy:
    - Users generate multiple addresses
- Result:
    - Hard to track identity

## 🔑 7. Bitcoin Addresses & Keys
- Important:
    - Address = Hash of public key
    - Private key = ownership proof
- Key Flow:
    - Private Key → Generate Public Key → Generate Address
- Key Insight:
- You don’t store coins
- 👉 You store keys

## ⚠️ 8. Loss of Private Key
Critical Concept:
Lose private key → Lose bitcoins forever
Why?
No recovery mechanism
No central authority
Real Issue:
Many bitcoins lost permanently

## 💳 9. Real-Life Bitcoin Payments
Process:
Receiver shares address (QR code)
Sender scans it
Sender signs transaction
Transaction broadcast
Example:
Like:
UPI / Paytm
QR scan payment
Requirement:
Secure storage of private key

## 🔁 10. Bitcoin Exchanges
1. 🔹 Centralized Exchanges
- Examples:
WazirX
CoinDCX
Features:
Account creation (KYC)
Buy/sell Bitcoin
Convert to INR
- Use:
Trading (like stock market)

2. 🔹 Decentralized Exchanges
No central authority
- Advantage:
More privacy
- Challenge:
No recovery if something fails

- 📌 Important Concept
    - 👉 Bitcoin = Not physical coin
    - Owning Bitcoin = Owning private key
