# Nakamoto Consensus & Proof of Work – Detailed

## . Nakamoto Consensus
- Consensus mechanism used in Bitcoin
- Based on Proof of Work (PoW)
- Key Idea:
```yml
        Open network + No trust
                ↓
        Use computational puzzle
                ↓
        First valid solution wins
```
- Purpose:
    - Achieve agreement in permissionless network

## ⛏️ 3. Block Mining Process
- Step-by-Step:
    1. Collect transactions
    2. Create block
    3. Compute Merkle Root
    4. Add:
        - Previous block hash
    5. Timestamp
    6. Try different nonce values
    7. Find valid hash
- Outcome:
    - First miner to solve:
        - Broadcasts block
        - Adds to blockchain

## 🎯 4. Challenge–Response Mechanism
- Network gives challenge
- Miners respond with proof
- Challenge:
    - Find nonce
- Response:
- Valid hash
- Insight:
    - Work done = Proof

## ⚖️ 6. Safety vs Liveness (CRITICAL)
1. 🔹 Safety (Split into 2 parts)
    1. Safety 1:
    - Block must be valid
    - Transactions verified
    - ✔️ Ensured in PoW

    2. Safety 2:
    - All nodes agree on same block
    ❌ Not guaranteed immediately

2. 🔹 Liveness:
- System continues to add blocks
- ✔️ Prioritized in PoW

3. Trade-off:
- PoW → Liveness > Safety

## ⚠️ 7. Why Safety 2 is Difficult?
- Miners don’t know each other
- Network is asynchronous
- Cannot coordinate instantly
- Result:
    - Multiple valid blocks possible

## 🔍 8. Block Validation
- After block is mined:
- Other nodes receive block
- Verify:
    - Hash condition
    - Transactions
    - Accept block
- Important:
    - Verification is fast
    - Mining is slow

## 📡 9. Gossip-Based Propagation
- Process:
    - Miner → Neighbor nodes → Entire network
- Features:
    - Decentralized
    - Multi-hop communication

## 🔁 10. Handling Transactions
- Each miner has:
- Unconfirmed Transaction Pool
- Important:
    - Pools differ across miners
    - Due to network delays
- Result:
    - Different miners → Different blocks

## ⚠️ 11. Key Limitation (IMPORTANT)
- Problem:
    - Two miners find valid block at same time
- Result:
    - Temporary fork
- 👉 Which block should be accepted?
- Answer:
    - Solved later using:   
        - Longest Chain Rule
