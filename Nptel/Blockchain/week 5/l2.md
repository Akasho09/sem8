# Introduction to Ethereum

## 🌐 1. What is Ethereum?
- A permissionless blockchain platform
- Supports:
    - Cryptocurrency (Ether)
    - Smart Contracts
- Key Feature:
    - Ethereum = Blockchain + Programmable Logic
- Important:
    - Launched in 2015
    - Designed to run decentralized applications (DApps)

## ⚖️ 2. Ethereum vs Bitcoin
| Feature         | Bitcoin          | Ethereum            |
| --------------- | ---------------- | ------------------- |
| Purpose         | Digital currency | Platform + currency |
| Smart Contracts | ❌ No             | ✅ Yes               |
| Flexibility     | Limited          | High                |

- Key Difference:
    - 👉 Ethereum supports code execution (smart contracts)
    - 📌 From transcript: Ethereum powers applications that no one can shut down

## 🌍 3. Ethereum Network
- Fully decentralized P2P network
- No central server
- Nodes:
    - Computers running Ethereum client
- Each Node:
    - Stores blockchain
    - Verifies transactions
    - Communicates with other nodes
- Structure:
    - Node ↔ Node ↔ Node → P2P Network

## 🧠 4. Ethereum Node Components
- Each node (client) includes:
    - Consensus Module (PoW / others)
    - State (ledger data)
    - EVM (Ethereum Virtual Machine)
    - Transaction Pool (Mempool)
    - P2P Communication Module
- 🔥 Key Component:
    - 👉 EVM = Executes smart contracts

## 💻 5. Ethereum Client (Geth)
- Software to connect to Ethereum network
- Popular Client:
    - 👉 Go-Ethereum (Geth)
- Functions:
    - Connect to network
    - Manage accounts
    - Send transactions
    - Query blockchain
- Important:
    - Acts as entry point to Ethereum network

## 🌐 6. Ethereum Networks
- 🔹 Mainnet
    - Real Ethereum network
    - Uses real Ether
- 🔹 Testnets (for testing)
- Examples:
    - Goerli
    - Rinkeby
    - Ropsten
- Key Idea:
    - Testnets → Free testing
    - Mainnet → Real transactions

## 🔑 7. Ethereum Accounts
- Creation:
- Command:
    - geth account new
- Features:
- Each account has:
    - Public key (address)
    - Private key
- Important:
    - Private key is encrypted (not stored directly)
- 📌 From transcript: stored securely using password

## ⚙️ 8. Sync Modes
| Mode  | Description                 |
| ----- | --------------------------- |
| Full  | Downloads entire blockchain |
| Fast  | Partial + verification      |
| Snap  | Optimized fast sync         |
| Light | Minimal data                |
> 👉 Light mode (fastest)

## 🔌 9. Connecting to Ethereum Network
- Command Example:
    - geth --goerli --syncmode light
- With HTTP API:
    - geth --goerli --syncmode light --http
- Result:
- Connects to Goerli testnet
- Starts RPC server

## 🔗 10. JSON-RPC & HTTP API
- Purpose:
    - Communicate with Ethereum client
- Method:
    - Send HTTP POST request
- Example Method:
    - eth_getBalance

## 📊 11. Querying Account Balance
```json
Request Format:
{
  "jsonrpc":"2.0",
  "method":"eth_getBalance",
  "params":["address","latest"],
  "id":1
}
```
```yml
Output:
0x29a...
```
👉 Value is in hexadecimal
- Convert to decimal:
echo $((16#HEX_VALUE))

## 💰 12. Ether Units
- Smallest unit:
    - 👉 Wei
- Conversion:
    - 1 Ether = 10^18 Wei
- Other Units:
    - Gwei
    - Kwei
    - Milliether
- Key Idea:
    - Balance is stored in Wei

# 📌 Final Summary
Ethereum = Blockchain + Smart Contracts
Uses:
Nodes
Clients (Geth)
P2P network
Workflow:
User → Ethereum Client → Network → Blockchain
