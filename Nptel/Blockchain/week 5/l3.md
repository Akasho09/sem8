# Ethereum Transactions & Geth Practical

## What is an Ethereum Transaction?
- A cryptographically signed instruction
- Sent from one account to another
- Purpose:
    - Transfer Ether
    - Execute smart contracts
    - Update blockchain state
- Key Idea:
    - Transaction = Signed Message + State Change

## 🔐 2. Cryptographic Signing
- Requirement:
    - Must use private key
- Why?
    - To prove ownership
    - To prevent fraud
- Flow:
    - Private Key → Sign Transaction → Broadcast → Verify using Public Key

## 💸 3. Gas (VERY IMPORTANT)
- Fee required to execute a transaction
- Why gas?
    - Transactions need:
        - Computation
        - Validation
- Paid in:
    - 👉 Ether
- Key Idea:
    - More computation → More gas required

## 🪙 4. Getting Ether (Faucet)
- Problem:
    - Test networks need Ether
- Solution:
    - 👉 Faucet
- What is Faucet?
    - Tool to get free Ether (testnet only)
- Example:
    - Goerli faucet
- Limitation:
    - Limited Ether per user
    - Time restrictions
- 📌 Prevents misuse (DoS attacks)

## 🔓 5. Unlocking Account in Geth
- Why needed?
    - To use private key for transactions
- Command:
    - geth --goerli --unlock <account> --password pwd.txt --allow-insecure-unlock
- Important:
    - Password stored in file
    - Account unlocked for sending transactions

## 💻 6. Sending Transaction
- Method:
    - eth_sendTransaction
- Parameters:
    - from → sender address
    - to → receiver address
    - value → amount (in wei, hex format)
- Example JSON:
```json
{
  "method":"eth_sendTransaction",
  "params":[{
    "from":"A",
    "to":"B",
    "value":"0x..."
  }]
}
```
- Output:
    - Transaction Hash

## 🔗 7. Transaction Hash
- Unique identifier of transaction
- Purpose:
    - Track transaction
    - Verify status
- Example:
    - 0xabc123...

## 📊 8. Monitoring Transaction
- Method:
    - eth_getTransactionByHash
- Input:
    - Transaction hash
- Output:
    - Block number
    - Status
    - Sender/receiver
    - Gas used

## 🌐 9. Using Etherscan
- Tool:
    - Blockchain explorer
- Example:
    - Goerli Etherscan
- Use:
    - Paste transaction hash
- Check:
    - Pending
    - Success
    - Block details

## 📦 10. Query Block Details
- Method:
    - eth_getBlockByNumber
- Input:
    - Block number (hex)
- Output includes:
    - Block hash
    - Miner
    - Gas used
    - Transactions list
- 🔍 Example Block Info
    - Difficulty
    - Nonce
    - Gas limit
    - Transactions inside block

## 💰 11. Value Representation
- Important:
    - Value sent is in Wei (hex format)
- Example:
    - 0.1 Ether = 10^17 Wei
- Convert:
    - echo $((16#HEX_VALUE))

## 🔄 12. Complete Transaction Flow
1. Create transaction
2. Sign using private key
3. Send via Geth (RPC)
4. Get transaction hash
5. Monitor via Etherscan or RPC
6. Included in block
7. Confirmed
