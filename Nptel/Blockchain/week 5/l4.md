# Web3.js & DApps in Ethereum

## 🌐 1. What is Web3.js?
- A JavaScript SDK (Software Development Kit)
    - Used to interact with Ethereum network
- Purpose:
    - Replace manual RPC calls
    - Simplify blockchain interaction
- Key Idea:
    - Web3.js = Bridge between Application & Ethereum Network

## 🧩 2. What are DApps?
- Decentralized Applications
- Run on blockchain instead of centralized server
- Features:
    - No central authority
    - Transparent
    - Trustless
    - Immutable
- Components:
    - DApp = Smart Contract + User Interface (UI)

## 🏗️ 3. DApp Architecture
- Structure:
    - User → DApp UI → Web3.js → Geth → Ethereum Network
- Explanation:
    - UI → Frontend interface
    - Web3.js → Communication layer
    - Geth → Ethereum client
    - Network → Blockchain
- Key Insight:
- 👉 Smart contracts run on Ethereum nodes, not UI

## 🔗 4. Role of Smart Contracts
- Deployed on blockchain
- Executed by all nodes
- Output determined by:
    - 👉 Consensus mechanism
- UI Role:
    - Send transactions
    - Query smart contracts

## 🔌 5. Connecting Web3.js to Geth
- Methods:
    - HTTP (most common)
    - WebSocket
    - IPC
- Example:
    - var web3 = new Web3("http://localhost:8545");
- Meaning:
    - Connects Web3.js → Geth via RPC

## 💻 6. Installing Web3.js
- Steps:
1. Install Node.js
2. Install npm
3. Install Web3:
    - npm install web3
- Verify:
require("web3")

## 📊 7. Querying Balance using Web3.js
- Code:
```js
web3.eth.getBalance(address)
.then(console.log)
```
- Output:
    - Balance in Wei (decimal format)
- Important:
- Web3 converts:
    - Hex → Decimal automatically

## ⚡ 8. Promise-based Execution
- Concept:
    - Web3 functions are asynchronous
- Flow:
    - Function call → Returns Promise → Executes later
- Example:
    - web3.eth.getBalance(addr).then(result => console.log(result))
- Insight:
    - Immediate return = Promise
    - Actual result comes later

## 📁 9. Writing Program (Node.js File)
- Example:
```js
var Web3 = require("web3");
var web3 = new Web3("http://localhost:8545");

web3.eth.getBalance("address")
.then(balance => console.log(balance));
```
Run:
```bash
node file.js
```

## 💸 10. Sending Transaction using Web3.js
1. Step 1: Define Transaction Object
```js
var tx = {
  from: "A",
  to: "B",
  value: web3.utils.numberToHex(100000000000000000)
};
```

2. Step 2: Send Transaction
```js
web3.eth.sendTransaction(tx)
.then(console.log);
```
- Output:
    - Transaction hash
    - Block number
    - Block hash
- Important:
    - Account must be unlocked
    - Must have Ether for gas

## 🔄 11. Transaction Flow using Web3.js
```yml
        Create transaction
        ↓
        Convert value to hex
        ↓
        Send using web3.eth.sendTransaction
        ↓
        Wait for mining
        ↓
        Receive transaction details
```

## 🌐 12. Monitoring Transaction

- Result:
    - Check status:
    - Pending
    - Confirmed

# 📌 Final Summary
Web3.js simplifies Ethereum interaction
DApps = UI + Smart Contracts
Geth acts as bridge to network
Key Workflow:
User → UI → Web3.js → Geth → Blockchain
