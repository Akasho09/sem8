## Which Ethereum transaction parameter ensures transaction ordering and prevents replay attacks for a given
account?
a. Gas
b. Value
c. Nonce
d. Data

c) Nonce
- Why this is correct
- In Ethereum, the nonce is a counter associated with each account:
- Starts from 0 and increases with every transaction
- Ensures transactions are processed in order
- Prevents replay attacks (same transaction can’t be reused)
