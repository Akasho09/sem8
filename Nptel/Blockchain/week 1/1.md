## What is Blockchain?
- Blockchain is a distributed, decentralized digital ledger that records transactions across multiple computers in a secure, transparent, and immutable way.
    - Distributed → Data is shared across many nodes (computers)
    - Decentralized → No central authority (like a bank)
    - Immutable → Once data is added, it cannot be altered
- Simple Idea:
    - A blockchain is like a shared Google Sheet:
    - Everyone can see it
    - No one can secretly change past data
    - Every update is recorded permanently

### 2. Structure of Blockchain
- Block Components:
- Each block contains:
    - Data → Transaction details
    - Hash → Unique identifier of the block
    - Previous Hash → Links to the previous block
- This creates a chain of blocks → hence Blockchain

### 3. How Blockchain Works
1. A transaction is requested
2. Transaction is broadcast to the network
3. Nodes validate the transaction
4. Transaction is added to a block
5. Block is added to the chain permanently

### 4. Key Features of Blockchain
1. Decentralization
No central authority controls the system
Power is distributed among nodes

2. Transparency
All transactions are visible to participants

3. Immutability
Data cannot be changed once recorded

4. Security
Uses cryptographic hashing
Very difficult to hack

5. Consensus Mechanism
- Agreement among nodes to validate transactions:
    - Proof of Work (PoW)
    - Proof of Stake (PoS)

### 5. Types of Blockchain
1. Public Blockchain
- Open to everyone
Example: Bitcoin, Ethereum

2. Private Blockchain
- Controlled by a single organization

3. Consortium Blockchain
- Controlled by a group of organizations

4. Hybrid Blockchain
Combination of public and private

### 6. Blockchain vs Traditional Systems
| Feature      | Traditional System | Blockchain                 |
| ------------ | ------------------ | -------------------------- |
| Control      | Centralized        | Decentralized              |
| Transparency | Limited            | High                       |
| Security     | Moderate           | High                       |
| Speed        | Faster (sometimes) | Slower (due to validation) |
| Trust        | Requires trust     | Trustless                  |


### 7. Importance of Blockchain
1. Eliminates Middlemen
No need for banks or intermediaries

2. Enhances Security
Cryptographic protection

3. Increases Transparency
All transactions are traceable

4. Reduces Cost
Fewer intermediaries → lower fees

5. Builds Trust
Trust is based on technology, not institutions

### 8. Real-World Applications
1. Finance
Cryptocurrencies like Bitcoin

2. Supply Chain
Track goods from origin to delivery

3. Healthcare
Secure patient records

4. Voting Systems
Transparent elections

5. Smart Contracts
Self-executing contracts on Ethereum

### 9. Advantages of Blockchain
- High security
- Transparency
- Decentralization
- Reduced fraud
- Faster cross-border transactions

### 10. Limitations of Blockchain
- Scalability issues
- High energy consumption (PoW)
- Regulatory uncertainty
- Slower transaction speed
