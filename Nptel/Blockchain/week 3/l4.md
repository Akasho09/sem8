# Blockchain Elements – II

## ⚡ 1. Block Generation Cost
- Mining requires solving a cryptographic puzzle
- Important:
    - Requires:
        - High computation
        - Time
        - Energy
- Insight:
    - More difficulty → More cost → More security

## 🔢 2. Hash Generation Rate
- Number of hashes computed per second
    - ~750 TeraHash/sec (ASIC hardware)
- Network ≈ 150 million TeraHash/sec
=> 👉 Massive computational effort

## 💻 3. Mining Hardware (ASIC)
- What is ASIC?
    - Application-Specific Integrated Circuit
- Purpose:
    - Designed only for mining
- Features:
    - Very fast
    - Very expensive
    - Not for normal users

## 🔥 4. Energy Consumption
- Bitcoin mining consumes huge energy
- Can power thousands of households
- Issue:
    - ❌ Environmental concern

## 🤝 5. Mining Pools
- Miners combine resources
    - To Increase chance of winning
- Examples:
    - F2Pool
    - AntPool
    - Binance Pool
- Key Idea:
    - More power together → Higher probability of mining

## 🌐 6. Blockchain Replication
- Every node stores full blockchain copy
- Size:
    - ~350 GB (Bitcoin)
- Importance:
    - Ensures consistency
    - Ensures decentralization

## 📦 7. Transactions in a Block
- Structure:
- Block contains:
    - Header
    - Transactions
- Example:
    - 2000+ transactions per block
- Each transaction has:
    - Transaction ID (hash)

## 🔄 9. Transaction Inputs & Outputs
- Transactions use:
    - Inputs
    - Outputs
- Example:
    - Input: 100 BTC
- Output:
    - 40 BTC → Bob
    - 60 BTC → Change
- Important:
    - Must spend entire input
    - Remaining returned as change.

## 🧠 10. UTXO Concept (Implicit)
- Coins exist as unspent outputs
- If 100 BTC received:
    - Spend 40 → remaining 60 becomes new UTXO

## ✍️ 11. Digital Signatures
- Purpose:
    - Verify ownership
- Process:
    - Sender signs transaction using private key
    - Receiver verifies using public key
- Ensures:
    - Authentication
    - Integrity

## 📜 12. Bitcoin Scripts
- Small programs used in transactions
- Types:
1. ScriptPubKey
- Defines conditions to spend

2. ScriptSig
- Provides proof to unlock
Concept:
- ScriptSig + ScriptPubKey → Execution → TRUE/FALSE

## 🔐 13. Pay-to-Public-Key-Hash (P2PKH)
Idea:
Payment made to hash of public key
Process:
Receiver sends public key hash
Sender locks coins to that hash
Receiver unlocks using private key
Benefit:
Secure
Privacy-friendly

## ⚙️ 14. Script Execution Model
Features:
Stack-based
Simple language
No loops (not Turing complete)
Why no loops?
Avoid infinite execution
Ensure fast validation
Result:
Safe execution
Predictable behavior


# 📌 Final Summary
- Mining is computationally expensive
- Blockchain ensures:
    - Security
    - Consistency
    - Decentralization
- Key Flow:
    - Transaction → Signed → Script → Verified → Added to block
