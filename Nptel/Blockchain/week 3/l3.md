# Blockchain Elements – I

## 🔗 1. What is Blockchain?
- A distributed ledger of transactions
- Maintained across multiple nodes
- Key Properties:
    - Append-only (cannot modify past data)
    - Digitally signed transactions
    - Replicated across network
- Example:
    - Alice → Bob (5 BTC)
    - Bob → Carol (2 BTC)

## 📦 2. What is a Block?
- A container of transactions
- Structure:
- Each block has:
    - Transactions
    - Block Header

### 🧱 3. Structure of a Block
- Block = Block Header + List of Transactions
- Each block can have ~500–1000 transactions
- Block size ≈ 1 MB (Bitcoin)

## 🔗 4. Linking of Blocks
- Blocks are connected using hash pointers
    - Block 2 → contains hash of Block 1
    - Block 3 → contains hash of Block 2
- Result:
    - Forms a chain (Blockchain)

## 🧠 5. Block Header (VERY IMPORTANT)
- Contains:
    - Previous Block Hash
    - Merkle Root
    - Timestamp
    - Difficulty Bits
    - Nonce
    - Version
- Purpose:
    - Used to compute block hash
    - Links blocks together

## 🌳 6. Merkle Tree & Merkle Root
- Transactions are hashed in pairs
- Process:
    - T1 + T2 → H1
    - T3 + T4 → H2
- H1 + H2 → Root Hash (Merkle Root)
- Importance:
    - Efficient verification
    - Detects tampering

## ⛏️ 7. Mining of a Block
- Process of generating a valid block hash
- Goal:
    - Find nonce such that:
        - Hash(Block Header) < Target
- Important:
    - Requires high computation
    - Based on trial and error

## 🧩 8. Block Generation Puzzle
- Problem:
    - Find nonce such that:
    - Hash has required number of leading zeros
- Example:
    - Hash = 000000ABC...
- Key Idea:
    - Hard to find
    - Easy to verify

## ⚙️ 9. Difficulty Level
- Defined by:
    - Difficulty Bits (bits field)
- Determines:
    - Number of leading zeros required
- Insight:
    - Higher difficulty → more zeros → harder mining

## 🔢 10. Block Hash Calculation
- Inputs used:
- Block Hash = Hash(
    Previous Hash +
    Merkle Root +
    Timestamp +
    Difficulty Bits +
    Nonce +
    Version
)
- Important:
    - Only Nonce is unknown
    - Miners try different nonce values

## 🔁 11. Tamper-Proof Property
- If attacker changes data:
    - Transaction changes
    - Merkle Root changes
    - Block Hash changes
    - All future blocks must change
- Result:
    - 👉 Extremely difficult to tamper
- ⚠️ Example from Transcript
- If block 600000 is changed:
    - Must recompute:
    - Block 600001
    - Block 600002
    ...
    Up to latest block
- 👉 Computationally infeasible

## 🔍 12. Verification of Block Hash
- Anyone can verify block hash
- Uses:
    - Block header data
    - Hash function
- Important Concept:
    - Mining = hard
    - Verification = easy

# 📌 Final Summary
- Blockchain = chain of blocks
- Each block contains:
    - Transactions
    - Block header
- Key Security Mechanisms:
    - Hash linking
    - Merkle tree
    - Proof of Work 
- Core Idea:
    - Change in data → Change in hash → Chain breaks
