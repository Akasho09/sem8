#  Bitcoin Mining and Beyond

## Open Consensus
- In an open network, participants are unknown
- System cannot trust anyone
- 👉 Solution:
    - Give a challenge (puzzle)
    - Whoever solves it first → becomes leader

## ⛏️ 2. Bitcoin Mining
- Process of adding new blocks to blockchain
- 👉 Mining = Consensus mechanism in Bitcoin
- Why called “Mining”?
    - Because it generates new bitcoins 
    - Similar to mining gold

## Role of Miners
- Miners are special nodes in network
- Tasks:
    - Collect transactions
    - Verify them
    - Create a block
    - Solve puzzle
    - Add block to blockchain
- Important:
    - Anyone can become a miner
    - No registration required

## 📦 4. Block Creation Process
- Users send transactions
- Miners collect transactions
- Combine them into a block
- Compete to add block

## 🧩 5. Puzzle Solving (Proof of Work)
- Many miners → many blocks
- Only one block must be added
- 👉 Solution:
    - Use puzzle solving
- How it works:
    - All miners solve puzzle independently
    - First one to solve → wins
- Mathematical Form:
    - Given: x, y  
    - y = hash(x + N)
        - Find: N (nonce)
    
### Key Properties:
- No deterministic solution
- Requires trial and error
- Needs high computation power
- Result:
    - Winner provides proof
    - Others verify it easily

## 🔄 6. Fairness in Mining
- No miner always wins
- Winners change randomly
- 👉 Ensures:
- Decentralization
- No monopoly

## 💡 7. Need for Incentives
- Problem:
    - Mining requires:
    - Time
    - Electricity
    - Computation
👉 Why will people do it?

### 💰 8. Incentive Mechanism
- Solution:
    - Give reward in Bitcoin
- 👉 If miner adds block:
    - Gets bitcoins
    - Gets transaction fees
- Key Idea:
> Solve puzzle → Add block → Earn Bitcoin

## 🧩 17. Introduction to DApps
- Idea:
- Blockchain can store:
    - Data
    - Executable code
- Key Concept:
    - Transaction = Code execution
- Result:
    - Applications run on blockchain

## 📌 Final Summary
- Mining = consensus + reward system
- PoW = puzzle solving
- Incentives = bitcoin rewards
- Blockchain works like:
    - Bank + Network + Computer system
