## Linear Classification
- A linear classifier separates data using a linear decision boundary.
👉 In 2D → a line
👉 In 3D → a plane
👉 In n-D → a hyperplane

### Mathematical Form
> y = w^T * x + b
- w → weights vector
- x → input features
- b → bias

### 🔹 Decision Rule
Class= { 1    ​if wTx+b≥0
         0    otherwise
       }
        
## Logistic Regression
- A classification algorithm that predicts probability of a class.
- 👉 Used for binary classification


## Linear Discriminant Analysis (LDA)
- A classification + dimensionality reduction technique
- 👉 Projects data to maximize class separability

### 🔹 Key Idea
- 👉 Maximize:
distance between class means
- 👉 Minimize:
variance within class

### 🔹 Steps
- Compute mean of each class
- Compute within-class scatter matrix (Sw)
- Compute between-class scatter matrix (Sb)
- Solve eigenvalue problem
- Project data

| Feature           | Logistic Regression | LDA                          |
| ----------------- | ------------------- | ---------------------------- |
| Type              | Discriminative      | Generative                   |
| Assumptions       | None strict         | Gaussian + equal covariance  |
| Output            | Probability         | Class separation             |
| Works better when | Data is not normal  | Data is normally distributed |
