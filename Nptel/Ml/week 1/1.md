## 🔹 1. What is Statistical Decision Theory?
- Statistical Decision Theory provides a mathematical framework for making decisions under uncertainty using probability.
- Goal : To choose the best action (prediction/model) based on available data.
- 📌 Core Components:
1. Data (D)
- Observations used to learn patterns.
2. Model (f(x))
- A function that maps input → output.
3. Loss Function (L(y, ŷ))
Measures error between actual value (y) and predicted value (ŷ).
4. Risk (Expected Loss)
- Average loss over all possible data:
> 👉 Risk = Expected Loss

### 📊 Types of Risk:
1. Empirical Risk (Training Error)
- Error on training data.
2. True Risk (Generalization Error)
- Error on unseen data.

## 🔹 2. Regression
- Regression in machine learning is a `supervised` learning(where a model learns from `labelled` data) technique used to predict continuous, numerical output values based on input data patterns
- 👉 Example:
    - Predicting house prices
    - Predicting temperature.

1. 📈 Linear Regression Model:
> y=wx+b
- Where:
    - w = slope
    - b = intercept
- 📌 Loss Function (Mean Squared Error):
> MSE= 1/n * ​∑(y−ŷ​)2
- 📌 Key Points:
    - Output is numeric
    - Sensitive to outliers
    - Easy to interpret

## 🔹 3. Classification
- Classification is used when the output variable is categorical.
- 👉 Example:
    - Spam vs Not Spam
    - Disease vs No Disease
- 📊 Types:
1. Binary Classification
- 2 classes (Yes/No)
2. Multiclass Classification
- More than 2 classes

## Logistic Regression 
> Logistic Regression is a classification algorithm, even though its name says “regression” 🙂
- It is used to predict probabilities and classify data into categories (usually 0 or 1).
- Instead of giving a continuous output like linear regression, it uses a sigmoid (logistic) function to map values between 0 and 1:
> P(y=1)= 1/(1+e^-z)
- Where:
    - z=wX+b
    - Output is a probability
- ⚖️ Decision Rule
    - If probability ≥ 0.5 → Class 1
    - If probability < 0.5 → Class 0

| Feature  | Linear Regression | Logistic Regression |
| -------- | ----------------- | ------------------- |
| Output   | Continuous        | Categorical         |
| Range    | (-∞, +∞)          | (0, 1)              |
| Use case | Price, marks      | Yes/No, Spam        |

- 📌 Loss Function:
> Log Loss / Cross Entropy

- 📌 Key Points:
    - Output is discrete/class labels
    - Uses probability for prediction
    - Decision boundary separates classes

## 🔹 4. Bias-Variance Tradeoff
- Total Error Decomposition:
> Error=Bias^2+ Variance+ Irreducible Error

1.  🔹 Bias
- Error due to oversimplified model
- Model assumptions are too strong
- 👉 Example:
- Linear model for non-linear data
- 📉 Leads to:
    - Underfitting

2. 🔹 Variance
- Error due to model sensitivity to data
- Model changes a lot with small data changes
- 📈 Leads to:
    - Overfitting

| Model Type | Bias | Variance | Result       |
| ---------- | ---- | -------- | ------------ |
| Simple     | High | Low      | Underfitting |
| Complex    | Low  | High     | Overfitting  |

- 📊 Visualization Insight:
    - As complexity ↑ → Bias ↓ but Variance ↑
    - Need optimal balance

- 🎯 Goal: Minimize total error by balancing both.

1. ❌ Underfitting:
- Model too simple
- High bias
- Poor performance on both train & test

2. ❌ Overfitting:
- Model too complex
- High variance
- Good on train, bad on test
