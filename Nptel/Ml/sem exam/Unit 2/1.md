# Regression
- Regression is used to predict continuous (numerical) values

## 🔹 Types of Regression:
1. Linear Regression

2. Multiple Linear Regression

## 🔹 Cost Function (MSE):
> J(θ)=1/n * ∑(ypred​−yactual​)^2

## Multivariate (Multiple) Linear Regression
- Use multiple features to predict output.
> y=β0​+β1​x1​+β2​x2​+⋯+βp​xp​+ϵ

- 📌 Example:
- Predict house price using:
    - Area
    - Bedrooms
    - Location

- 📌 Matrix Form:
> Y=Xβ+ϵ

- 📌 Challenges:
- Multicollinearity (features highly correlated)
- Overfitting when features ↑

### 📊 Types:
1. Best Subset Selection
- Try all possible combinations
- Choose best based on metric
- ⚠️ Expensive:  2^p models

2. Forward Selection
- Start with no variables
- Add one by one

3. Backward Elimination
- Start with all variables
- Remove least useful

- 📌 Evaluation Metrics:
    - Adjusted R^2
    - AIC (Akaike Information Criterion)
    - BIC (Bayesian Information Criterion)

- 📌 Goal:
    - Reduce complexity
    - Improve interpretability

4. Shrinkage Methods (Regularization)
- Used to reduce overfitting by shrinking coefficients.

A. Ridge Regression
> Minimize RSS+λ ∑βj^2​
📌 Key Points:
- Shrinks coefficients toward zero
- Does NOT set them exactly zero
- Good for multicollinearity

B. Lasso Regression
> Minimize RSS+ λ*∑∣β|
- 📌 Key Points:
    - Can make coefficients exactly zero
    - Performs feature selection

| Method | Shrinks | Feature Selection |
| ------ | ------- | ----------------- |
| Ridge  | Yes     | No                |
| Lasso  | Yes     | Yes               |

### 🔹 5. Principal Component Regression (PCR)
- 📌 Idea:
- First apply PCA (Principal Component Analysis)
- Then perform regression on principal components
- 📌 Steps:
- Transform features → principal components
- Select top components
- Run regression
- 📌 Why use PCR?
- Reduces dimensionality
- Removes multicollinearity
- 📌 Limitation:
- Components chosen without considering output 𝑦

### 🔹 6. Partial Least Squares (PLS)
- Like PCR, but considers output 𝑦 while creating components.

| Feature           | PCR      | PLS          |
| ----------------- | -------- | ------------ |
| Uses (y)?         | ❌ No     | ✅ Yes        |
| Better prediction | Moderate | Often better |

📌 Advantage:
- Balances feature variance + prediction power

# Gradient Descent 
is an optimization algorithm used in Machine Learning to minimize a loss (error) function by updating model parameters step-by-step.
> You’re standing on a hill and want to reach the lowest point (minimum error) → you keep moving downhill using the slope.
- 🔹 Core Idea
    - Move in the opposite direction of the gradient (slope)
    - Repeat until you reach minimum error

## 🔹 Key Formula
> θ = θ − α * ∂J(θ)​/∂θ
- Where:
θ (theta) → model parameters (weights)
α (alpha) → learning rate
J(θ) → loss function
∂J/∂θ → gradient (slope)

## 🔹 Steps of Gradient Descent
- Initialize parameters (θ) randomly
- Compute loss function
- Calculate gradient
- Update parameters using formula
- Repeat until convergence

## Types of Gradient Descent
1. Batch Gradient Descent
Uses entire dataset
Accurate but slow

2. Stochastic Gradient Descent (SGD)
Uses one data point at a time
Faster but noisy

3. Mini-Batch Gradient Descent
Uses small batches
Most commonly used (balance of speed + stability)

## 🔹 Learning Rate (α)
- Controls step size
👉 Too large → may overshoot
👉 Too small → slow learning

## 🔹 Convergence
- Stops when:
    - Gradient ≈ 0
    - Loss stops decreasing

## 🔹 Example Use Cases
Linear Regression
Logistic Regression
Neural Networks (Backpropagation uses GD)

## 🔥 Advantages
Simple and widely used
Works for large models (Deep Learning)

## ⚠️ Challenges
Can get stuck in local minima
Sensitive to learning rate
Slow for complex surfaces

# 🔷 3. SVM (Support Vector Machine)
- Supervised learning algorithm used for:
    - Classification
    - Regression
- 🔹 Key Idea:
Find best boundary that separates classes

## 🔹 Hyperplane:
> w⋅x+b=0

## 🔹 Support Vectors:
Points closest to boundary
Define margin

## 🔹 Margin:
Distance between boundary and nearest points

## 🔹 Objective:
Maximize margin

## 🔹 Types:
1. Linear SVM
Straight line separation

2. Non-linear SVM
Uses kernel trick

## 🔹 Kernel Trick:
- Convert data into higher dimension
- Examples:
Polynomial
RBF (Gaussian)

# 📏 4. Decision Boundary
- Line/curve that separates different classes
- 🔹 Examples:
    - Linear boundary → straight line
    - Non-linear → curve

- 🔹 In SVM:
    - Optimal boundary = Maximum margin separator

## 🔹 Visualization:
```yml
Class A | Boundary | Class B
```
- 🔹 Importance:
Determines classification accuracy

## 📊 5. Generalization Performance
- Ability of model to perform well on unseen data
- 🔹 Key Idea:
    - Train well + Perform well on new data
- 🔹 Problems:
    - 🔴 Overfitting
    Model learns noise
    High training accuracy
    Low test accuracy
    - 🔴 Underfitting
    Model too simple
    Poor performance on both

## 🔹 Solutions:
1. For Overfitting:
Regularization
Dropout
More data

2. For Underfitting:
Increase model complexity
Better features

## 🔹 Evaluation Metrics:
Mean Squared Error (MSE)
Accuracy
Cross-validation
