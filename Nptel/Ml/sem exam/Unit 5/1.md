# Machine Learning

## 🌳 1. Decision Tree
- A tree-based model used for:
    - Classification
    - Regression
- 🔹 Structure:
    - Root → Internal Nodes → Leaf Nodes
- 🔹 Key Idea:
    - Split data based on best feature
- 🔹 Splitting Criteria:
1. Entropy:
> H(S)= − ∑pi * ​log2​pi​

2. Information Gain:
> IG=H(parent)−∑(  H(child) * ∣child∣/∣parent∣ )

### 🔹 Goal:
- Maximize information gain

- 🔹 Numerical Example (Concept):
Choose feature that gives:
Maximum reduction in entropy

- 🔹 Advantages:
Easy to understand
Works for categorical & numerical data

- 🔹 Limitations:
Overfitting
Sensitive to noise

## ✂️ 2. Pruning
- Technique to reduce overfitting
- 🔹 Types:
1. 🔹 (A) Pre-Pruning
Stop tree growth early
- Methods:
Max depth limit
Min samples split

2. 🔹 (B) Post-Pruning
Build full tree → then remove branches

- 🔹 Key Idea:
Simpler tree → Better generalization

## 🔗 3. Markov Random Field (MRF)
- Undirected graphical model
- 🔹 Key Idea:
A node depends only on its neighbors

- 🔹 Property:
    - Markov Property:
    P(X | neighbors) independent of rest

- 🔹 Example:
Image processing:
Pixel depends on nearby pixels

- 🔹 Applications:
Computer vision
NLP
Image segmentation

## 🔁 4. Hidden Markov Model (HMM)
- Statistical model where:
States are hidden
Observations are visible

- 🔹 Key Idea:
Hidden states generate observable outputs

- 🔹 Components:
States (hidden)
Observations
Transition probabilities
Emission probabilities

- 🔹 Diagram:
Hidden States → Observations

- 🔹 Example:
- Weather prediction:
| State | Observation |
| ----- | ----------- |
| Rainy | Umbrella    |
| Sunny | No umbrella |


## 🔢 5. HMM Problems (IMPORTANT)
1. Evaluation Problem
👉 Find probability of observation

2. Decoding Problem
👉 Find most likely hidden states
👉 Algorithm: Viterbi

3. Learning Problem
👉 Estimate parameters
👉 Algorithm: Baum-Welch

| Feature    | MRF        | HMM            |
| ---------- | ---------- | -------------- |
| Graph      | Undirected | Directed       |
| States     | Visible    | Hidden         |
| Dependency | Neighbors  | Previous state |
| Use        | Images     | Sequences      |
