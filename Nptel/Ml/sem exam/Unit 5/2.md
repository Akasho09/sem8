# 1. Decision Tree (Numerical Attributes)
- A Decision Tree is a supervised learning algorithm used for:
    - Classification
    - Regression
- It splits data into branches based on feature values.
- When attributes are numerical (continuous), the tree creates split conditions such as:
    - x<threshold
    - or
    - x≥threshold
- Steps for Numerical Decision Tree
    - Select a feature.
    - Choose the best threshold value.
    - Split dataset into subsets.
    - Repeat recursively until stopping condition.
- Example
- Suppose:
Age	Buy Product
20	No
35	Yes
40	Yes
- Possible split:
```yml
Age < 30 ?
   ├── Yes → No
   └── No  → Yes
```

## Splitting Criteria
1. (a) Entropy
- Measures impurity.
> Entropy(S)=−∑pi.log2pi

2. (b) Information Gain
> IG=Entropy(parent)−Entropy(children)
- Higher information gain → better split.

3. (c) Gini Index
Used in CART algorithm.
> Gini=1−∑pi^2

- Advantages
    Easy interpretation
    Handles numerical and categorical data
    No feature scaling required
- Disadvantages
    Overfitting
    Unstable for small changes in data

## 2. Pruning in Decision Trees
- Pruning reduces unnecessary branches from a decision tree to improve generalization and reduce overfitting.

- Types of Pruning
1. (a) Pre-Pruning (Early Stopping)
- Stops tree growth before it becomes too complex.
- Conditions
    Maximum depth reached
    Minimum samples required
    Information gain below threshold
- Advantages
    Faster training
    Prevents overly large trees
- Disadvantages
    May stop too early (underfitting)

2. (b) Post-Pruning
First grow the full tree, then remove unnecessary branches.
- Methods
    Reduced Error Pruning
    Cost Complexity Pruning
- Advantages
    Better accuracy
    Better generalization
- Disadvantages
    More computational cost

| Feature             | Pre-Pruning     | Post-Pruning             |
| ------------------- | --------------- | ------------------------ |
| When Applied        | During training | After full tree creation |
| Complexity          | Lower           | Higher                   |
| Overfitting Control | Moderate        | Better                   |
| Risk                | Underfitting    | Less underfitting        |

# 3. Markov Random Field (MRF)
A Markov Random Field is an undirected probabilistic graphical model used to represent relationships between variables.
- It satisfies the Markov property:
- A node depends only on its neighboring nodes.
- Characteristics
    Undirected graph
    Represents spatial dependencies
    Widely used in image processing
- Mathematical Representation
- Joint probability:
> P(X)=1/Z​∏c​ψc​(Xc​)
- Where:
    - Z = normalization constant
    - ψc = clique potential function
- Example of MRF
- Image segmentation:
- Each pixel depends on neighboring pixels.
Pixel A —— Pixel B
   |           |
Pixel C —— Pixel D
- Nearby pixels likely have similar labels.
- Applications
    Image restoration
    Computer vision
    Medical imaging
    NLP
- Advantages
    Captures contextual information
    Good for spatial modeling
- Disadvantages
    Computationally expensive
    Complex inference

# 4. Hidden Markov Model (HMM)
- A Hidden Markov Model is a statistical model where:
- States are hidden
- Outputs are observable
- It is based on Markov processes.
- Components of HMM
1. Hidden States
Actual states not directly visible.

2. Observations
Visible outputs generated from hidden states.

3. Transition Probabilities
Probability of moving from one state to another.
A=[aij​]

4. Emission Probabilities
Probability of observation given a state.
B=[bj(k)]

5. Initial Probabilities
πi=P(qi)

| Feature      | MRF            | HMM        |
| ------------ | -------------- | ---------- |
| Graph Type   | Undirected     | Directed   |
| Dependencies | Neighbor-based | Sequential |
| Data Type    | Spatial        | Temporal   |
| Applications | Images         | Speech/NLP |
