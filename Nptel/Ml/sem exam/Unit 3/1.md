# 🔷 1. Linear Discriminant Algorithm (LDA)
- A classification algorithm used to separate classes
- Also used for dimensionality reduction
- 🔹 Key Idea:
    - Project data onto a line such that classes are well separated
- 🔹 Goal:
- Maximize:
Distance between class means
- Minimize:
Variance within each class
- 🔹 Formula Idea:
> w = (mean1​−mean2​)​ / variance

## 🔹 Working Steps:
1. Compute mean of each class
2. Compute within-class scatter
3. Compute between-class scatter
4. Find projection direction (w)
5. Project data onto that line

## 🔹 Decision Rule:
- If projected value > threshold → Class 1
- Else → Class 2

## 🔹 Example (Simple):
- suppose
Class A: marks of students who pass
Class B: marks of students who fail
- 👉 LDA finds a line separating pass/fail

## 🔹 Advantages:
Works well for linearly separable data
Reduces dimensions

## 🔹 Limitations:
Assumes normal distribution
Poor for non-linear data

# 📊 2. ROC Curve (Receiver Operating Characteristic)
- Graph to evaluate classification model performance
- 🔹 Axes:
X-axis → False Positive Rate (FPR)
Y-axis → True Positive Rate (TPR)
- 🔹 Formulas:
> TPR= TP /TP+FN
> FPR= FP+TN / FP
	​

## 🔹 Interpretation:
Closer to top-left corner → Better model
Diagonal line → Random model

## 🔹 AUC (Area Under Curve):
Value between 0 and 1

| AUC  | Meaning |
| ---- | ------- |
| 1    | Perfect |
| 0.5  | Random  |
| <0.5 | Bad     |

- 🔹 Key Insight:
Higher AUC → Better classifier

# 🌳 3. Bagging (Bootstrap Aggregating)
- Ensemble technique to reduce variance
- 🔹 Idea:
Train multiple models on different subsets of data

- 🔹 Steps:
Create multiple datasets (with replacement)
Train separate models
Combine predictions

- 🔹 Final Output:
Classification → Majority voting
Regression → Average

- 🔹 Example:
Random Forest = Bagging + Decision Trees

- 🔹 Advantages:
Reduces overfitting
Improves stability

- 🔹 Limitation:
Doesn’t reduce bias


# 🚀 4. Boosting
- Ensemble technique that focuses on weak learners
- 🔹 Key Idea:
Train models sequentially, correcting previous errors

- 🔹 Working:
Train model
Identify errors
Give more weight to misclassified data
Train next model

- 🔹 Final Prediction:
Weighted combination of all models

- 🔹 Popular Algorithms:
AdaBoost
Gradient Boosting
XGBoost

- 🔹 Advantages:
High accuracy
Reduces bias

- 🔹 Limitation:
Sensitive to noise
Slower than bagging

| Feature     | Bagging         | Boosting      |
| ----------- | --------------- | ------------- |
| Training    | Parallel        | Sequential    |
| Focus       | Reduce variance | Reduce bias   |
| Data        | Random subsets  | Weighted data |
| Overfitting | Less            | Can overfit   |

```yml
    LDA → Classification boundary
            ↓
    ROC → Evaluate model
            ↓
    Bagging → Reduce variance
            ↓
    Boosting → Improve accuracy
```
