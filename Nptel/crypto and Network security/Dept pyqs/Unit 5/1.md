# 🔐 What is a Digital Signature?
A digital signature is a cryptographic technique used to:
👉 verify the authenticity and integrity of a message
- 🎯 It ensures:
✅ Authentication (who sent it)
✅ Integrity (not modified)
✅ Non-repudiation (sender cannot deny)

- ⚙️ How Digital Signature Works
- It uses:
Hash function (like SHA)
Public-key cryptography (like RSA)

## ✍️ Signature Generation (Sender Side)
- Steps:
1. Take message M
2. Compute hash:
H=Hash(M)
3. Encrypt hash using private key:
- S=H^dmodn
👉 S = Digital Signature
4. Send:
Message M
Signature S

## 🔍 Signature Verification (Receiver Side)
- Steps:
1. Receive M and S
2. Compute hash:
H1=Hash(M)
3. Decrypt signature using public key:
H2=Semodn
4. Compare:
If H1=H2 → ✅ Valid
Else → ❌ Invalid
