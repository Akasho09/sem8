## What is Cryptography?
- Cryptography is the science of securing communication so that only the intended recipient can understand the message.
- Plain message → Encryption → Ciphertext
- Ciphertext → Decryption → Original message

### 🔹 Key Terms
- Plaintext: Original readable message
- Ciphertext: Encrypted unreadable message
- Encryption: Process of converting plaintext → ciphertext
- Decryption: Reverse process
- Key: Secret value used in encryption/decryption

### 🔹 Goals of Cryptography
- Confidentiality – Only authorized users can read data
- Integrity – Data is not altered. i.e + and - saath mai.
- Authentication – Verify identity
- Non-repudiation – Sender cannot deny sending

### 🔹 Types of Cryptography
1. Symmetric Key Cryptography
- Same key for encryption & decryption
- Faster but less secure for key sharing
2. Asymmetric Key Cryptography
- Two keys: Public + Private
- More secure but slower

## 📌 2. Classical Cryptosystem
- Classical cryptography refers to old/manual encryption techniques used before computers.
- 🔹 Types of Classical Ciphers

1. Substitution Cipher
- Each letter is replaced by another letter.

    1. Caesar Cipher
    - Shift letters by fixed number
    - Example: Shift 3
    - A → D
    - B → E
    👉 Formula:
    > Encryption: C=(P+k)mod26
    > Decryption: P=(C−k)mod26

    2. 🔸 (b) Monoalphabetic Cipher
    - Each letter maps to a fixed substitute
    - Example:
    > A → Q, B → W
    - ⚠️ Weakness: Frequency analysis can break it

    3. 🔸 (c) Playfair Cipher
    - Encrypts pairs of letters (digraphs)
    - Uses a 5×5 matrix
    - Rules:
        - Same row → shift right
        - Same column → shift down
        - Rectangle → swap columns

2. ✏️ 2. Transposition Cipher
- Letters remain same but positions change.

    1. 🔸 (a) Rail Fence Cipher
    - Write message in zigzag form.
    - Example:
    - HELLO →.   H L O
                E L
    - Ciphertext: HLOEL

    2. 🔸 (b) Columnar Transposition
    - Write text in rows
    - Read columns based on key


## 📌 3. Block Cipher
- A block cipher encrypts data in fixed-size blocks (e.g., 64 bits, 128 bits).
    - Input → Block of plaintext
    - Output → Block of ciphertext
- 🔹 Key Features
    - Works on blocks, not single characters
    - Uses same key for entire block
    - Provides strong security
- 🔹 Example Block Ciphers
    - DES (Data Encryption Standard)
    - AES (Advanced Encryption Standard)

- 🔹 Basic Structure
- Block ciphers use multiple rounds of:
    - Substitution (S-box)
    - Permutation (P-box)
    - Key mixing

- 🔹 Modes of Operation
1. ECB (Electronic Codebook)
- Each block encrypted independently
⚠️ Weak: Patterns visible

2. CBC (Cipher Block Chaining)
- Each block depends on previous block
✔️ More secure than ECB

3. CFB (Cipher Feedback)
- Converts block cipher → stream cipher

4. OFB (Output Feedback)
- Uses keystream independent of plaintext

5. CTR (Counter Mode)
- Uses counter values for encryption
✔️ Fast & parallelizable

- 🔹 Advantages of Block Cipher
High security
Resistant to brute force (modern algorithms)
Suitable for large data

- 🔹 Disadvantages
Slower than stream cipher
Needs padding if data size ≠ block size

## 📌 🔚 Summary
    - Cryptography ensures secure communication
    - Classical ciphers are simple but insecure today
    - Block ciphers are modern and powerful encryption methods


## Security Attacks in cryptography
- A security attack is any attempt to compromise the confidentiality, integrity, or availability of data.
- 👉 In simple terms:
- An attack tries to steal, modify, or disrupt information.

### 📌 2. Classification of Security Attacks
- Security attacks are mainly divided into two categories:

1. Passive Attacks (Monitoring Attacks)
- A passive attack tries to observe or monitor data without altering it.
- 👉 No change in data — only listening or spying
- 🔸 Types of Passive Attacks
    1. Release of Message Contents
    - Attacker reads confidential data
    - Example: Reading emails, messages

    2. Traffic Analysis
        - Even if data is encrypted, attacker studies:
        - Message frequency
        - Communication patterns
    - 👉 Example:
        - Who is talking to whom
        - How often messages are sent

    - 🔸 Characteristics
        - Hard to detect ❗
        - No modification of data
        - Focus on confidentiality
    - 🔸 Prevention
        - Encryption (AES, DES)
        - Secure communication channels

2. Active Attacks (Modification Attacks)
- An active attack involves modifying, deleting, or fabricating data.
- 👉 Data is altered or disrupted

- 🔸 Types of Active Attacks
1. Masquerade Attack
- Attacker pretends to be a legitimate user
- 👉 Example:
- Logging in using stolen credentials

2. Replay Attack
- Attacker captures data and retransmits it later
- 👉 Example:
- Reusing login authentication messages

3. Modification of Messages
- Attacker alters the original message
- 👉 Example:
- Changing bank transaction amount

4. Denial of Service (DoS)
- Prevents legitimate users from accessing services
- 👉 Example:
- Flooding a server with requests

- 🔸 Characteristics
- Easier to detect ✔️
- Affects:
    - Integrity
    - Availability
- 🔸 Prevention
    - Authentication techniques
    - Digital signatures
    - Firewalls & intrusion detection systems

### 📌 3. Other Important Attack Types
1. Brute Force Attack
- Trying all possible keys
- 👉 Prevention:
- Use strong encryption (AES-256)

2. Man-in-the-Middle (MITM)
- Attacker secretly intercepts communication
- 👉 Example:
- Fake Wi-Fi networks

3. Phishing Attack
- Trick users into revealing sensitive data
- 👉 Example:
- Fake login pages

4. Dictionary Attack
- Uses common passwords list

5. Side-Channel Attack
- Uses physical data like:
    - Timing
    - Power consumption

| Feature     | Passive Attack  | Active Attack            |
| ----------- | --------------- | ------------------------ |
| Data Change | ❌ No            | ✔️ Yes                   |
| Detection   | Difficult       | Easier                   |
| Impact      | Confidentiality | Integrity & Availability |
| Example     | Eavesdropping   | DoS, Replay              |

## What are Security Mechanisms?
- Security mechanisms are methods or techniques used to detect, prevent, or recover from security attacks.
👉 In simple terms:
- They are the tools used to protect data and systems.

2. Classification of Security Mechanisms
- According to OSI Security Architecture, security mechanisms are divided into:
- 1. Specific Security Mechanisms
- 2. Pervasive Security Mechanisms

1. Specific Security Mechanisms
- These are directly used to provide security services.

1. Encipherment (Encryption)
- Converts plaintext → ciphertext
- Ensures confidentiality
- 👉 Example:
    - AES, DES
    - ✔️ Prevents unauthorized access

2. Digital Signature
- Provides:
    - Authentication
    - Integrity
    - Non-repudiation
- 👉 Ensures message is from a valid sender

3. Access Control
- Restricts access to authorized users only
- 👉 Example:
- Login systems, permissions

4. Data Integrity Mechanism
- Ensures data is not altered
- 👉 Techniques:
- Hash functions (SHA, MD5)

5. Authentication Exchange
- Verifies identity of communicating parties
- 👉 Example:
- Passwords, OTP, biometrics

6. Traffic Padding
- Adds fake data to confuse attackers
- 👉 Prevents traffic analysis

7. Routing Control
- Controls route of data transmission
- 👉 Avoids insecure paths

8. Notarization
- Uses a trusted third party
- 👉 Example:
- Digital certificates

2. Pervasive Security Mechanisms
- These are general mechanisms that support overall security.

1. Trusted Functionality
- System components that are reliable and secure

2. Security Labels
- Classify data based on sensitivity
- 👉 Example:
- Confidential, Secret

3. Event Detection
- Detects security violations
- 👉 Example:
- Intrusion detection systems (IDS)

4. Security Audit Trail
- Keeps record of system activities
- 👉 Helps in tracking attacks

5. Security Recovery
- Restores system after attack
- 👉 Example:
- Backup & recovery systems

| Security Service | Mechanism Used             |
| ---------------- | -------------------------- |
| Confidentiality  | Encryption                 |
| Integrity        | Hashing, Digital Signature |
| Authentication   | Authentication Exchange    |
| Non-repudiation  | Digital Signature          |
| Access Control   | Access Control Mechanisms  |
