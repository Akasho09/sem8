1.  “Angle Quest: Deep Learning Approach for Tooth Segmentation and Axial Inclination Measurement in Orthopantomogram Radiographs” 
- 🧠 Methodology 
The paper proposes a fully automated deep learning + computer vision framework for:
1. Instance-level tooth segmentation
2. Automated mesiodistal axial inclination angle calculation
- The complete workflow consists of:
1. 1️⃣ Data Collection
110 OPG radiographs
Collected from A. B. Shetty Memorial Institute of Dental Sciences
Age group: 18–30 years
Ethical clearance obtained
Sample size statistically validated

2. 2️⃣ Annotation Strategy
Two types:
LabelMe-based polygon annotation
Manual split-mask refinement
(to separate overlapping roots of adjacent teeth)
Converted into COCO format for Mask R-CNN training.

3. 3️⃣ Data Augmentation
Controlled augmentation applied:
Horizontal flip
Vertical flip
Rotation (±15°)
Brightness/contrast adjustment
Gaussian blur
Final dataset:
110 original images
220 augmented
Total = 330 images

4. 4️⃣ Segmentation Model Selection
1. ❌ U-Net (Semantic Segmentation)
Trained up to 130 epochs
Failed in:
Overlapping roots
Low contrast regions

Individual tooth separation

2. ✅ Mask R-CNN (Instance Segmentation) — Final Model
Architecture:
Backbone: ResNet-50 + FPN
Framework: Detectron2
Model: mask_rcnn_R_50_FPN_3x
Training:
1000 iterations
Batch size: 2
128 RoI proposals
T4 GPU
Loss Function:
- L(total) =L(RPN−cls)+L(RPN−box)+L(ROI−cls)+L(ROI−box)+L(mask)

5. 5️⃣ Post-Segmentation Processing
After Mask R-CNN:
Bounding boxes removed
RGB mask converted to binary
Morphological operations applied
Otsu thresholding used
Connected Component Analysis (CCA)
Noise filtering (area < 2000 pixels removed)

6. 6️⃣ Midpoint & Axis Construction
For each tooth:
Minimum-area rectangle fitted

Top & bottom midpoints computed

Vertical tooth axis generated

7. 7️⃣ Reference Line Generation
Maxillary teeth: Orbitale-to-orbitale line

Mandibular teeth: Mental foramen-to-foramen line

Dentist selects reference points via interactive tool.

8. 8️⃣ Axial Inclination Calculation
Intersection of tooth axis & reference line

Determinant-based line intersection formula

Angle computed using vector dot-product method

9. 9️⃣ Statistical Validation

Compared AI-derived angles with manual dentist measurements

Tests used:

Shapiro–Wilk test

Levene’s test

Unpaired t-test (p < 0.05)

- 📊 Model Accuracy (Segmentation Performance)
As reported in the abstract and results section 
| Metric                            | Value    |
| --------------------------------- | -------- |
| **Precision**                     | **0.83** |
| **Recall**                        | **0.92** |
| **Dice Coefficient**              | **0.87** |
| **IoU (Intersection over Union)** | **0.77** |

Additionally:
5-fold cross-validation performed
Evaluated at both pixel-level and object-level

- 🎯 Final Outcome

The study concludes:

Reliable instance-level segmentation

Accurate mesiodistal axial inclination measurement

Reduced human error

Faster than manual (manual takes 10–12 minutes per OPG)

Clinically viable and scalable

Works with limited GPU resources





2. “Multiclass Segmentation using Teeth Attention Modules for Dental X-ray Images” 

- 🧠 Methodology 
- The paper proposes a multiclass tooth segmentation architecture that integrates:
✅ M-Net-like U-Net structure
✅ Swin Transformer
✅ Teeth Attention Block (TAB) (Novel Contribution)
✅ Multiscale Supervision
✅ Squared Dice Loss

- 🔹 1️⃣ Overall Architecture
The architecture consists of:
- ✔ Encoder–Decoder (U-Net-like / M-Net-like structure)
3×3 convolution layers
Batch Normalization
ReLU activation
Max-pooling for downsampling
Transposed convolution for upsampling
Skip connections between encoder and decoder

- ✔ Swin Transformer (at bottleneck)
Captures long-range dependencies
Uses window-based self-attention
Handles global contextual information
Improves segmentation of complex tooth structures

- ✔ Teeth Attention Block (TAB) — Novel Component
TAB:
Works as boundary-aware refinement filter
Focuses on tooth boundaries
Uses self-attention mechanism
Reduces noise and irrelevant regions
Enhances differentiation between adjacent/overlapping teeth
Integrated into skip connections

- 🔹 2️⃣ Preprocessing
Resize images to 1024×512
Normalize pixel intensities to [0,255]
Multiscale morphology operations
Noise reduction and contrast enhancement

- 🔹 3️⃣ Multiscale Supervision
Supervision applied:
On both encoder (left leg)
On decoder (right leg)
This improves:
Feature propagation
Multiscale representation
Class differentiation

- 🔹 4️⃣ Loss Function
They use Squared Dice Loss:
- L=1−2∑(yt2​+yp2​)+ϵ2∑(yt​⋅yp​)2+ϵ​
Why squared Dice?
Handles class imbalance
Gives more weight to boundary pixels
Improves segmentation precision

- 🔹 5️⃣ Dataset
540 panoramic dental X-ray images

Segmented into 32 tooth classes

FDI notation:

#11–#18

#21–#28

#31–#38

#41–#48

Split:

70% training

15% validation

15% testing

4. Integrated Segmentation and Detection Models for Dentex Challenge 2023”
Lanshan He, Yusheng Liu, Lisheng Wang
Shanghai Jiao Tong University


1️⃣ Objective of the Paper

The paper proposes an integrated segmentation + detection framework to:

Detect abnormal teeth from panoramic dental X-rays

Predict disease labels

Predict enumeration IDs (FDI notation)

The work was developed for Dentex Challenge 2023.

2️⃣ Overall Methodology (Pipeline)

The task is divided into two main subtasks, followed by matching:

Step 1: Tooth Detection
Step 2: Disease Detection
Step 3: Label Matching

(Shown in Fig. 1, page 2)

Instead of modifying a single detection head for multi-label prediction, the authors:

Solve tooth detection and disease detection separately

Merge results later

This simplifies model design and improves flexibility.

3️⃣ Dataset & Preprocessing

The dataset consists of 3 subsets:

Subset 1: Quadrant Labels

Each object labeled with quadrant ID

Subset 2: Tooth Labels

Labeled with:

Quadrant ID

Enumeration ID within quadrant

Converted to:

Global enumeration ID (1–32)

Subset 3: Disease Labels

Labeled with:

Quadrant ID

Enumeration ID

Disease ID

For training:

Only disease ID retained (quadrant + enumeration removed)

Format Conversion

Converted annotations into:

COCO format

YOLO format

Segmentation Preprocessing

Masks generated from JSON “segmentation” field

Images resized to 256×256

Augmentations:

Random vertical flip

Random crop

Random rotation

Detection Preprocessing

Default settings of downstream models used

4️⃣ Tooth Detection

Two approaches used:

A) Detection Model

Model used:

DINO (DETR-based)

Backbone: ResNet-50

Pretrained on COCO

B) Segmentation Models

Models used:

U-Net

SE U-Net (U-Net + Squeeze-and-Excitation blocks)

Two segmentation strategies:

Strategy 1: Whole Image Segmentation

Train on full panoramic image

Predict 32 classes
(Each class = enumeration ID)

Strategy 2: Quadrant-wise Segmentation

Step 1: Detect quadrants

Model: DiffusionDet

Trained on Subset 1

Step 2: Crop each quadrant

Masks converted:

Teeth in current quadrant → values 1–8

Teeth outside quadrant → label 9

Step 3: Train segmentation model per quadrant

Predict 9 classes

8 teeth

1 “not in quadrant” class

From Segmentation to Bounding Boxes

Keep largest connected component per label

Convert mask regions → bounding boxes

Restore quadrant boxes back to original image coordinates

5️⃣ Disease Detection

Two models used:

1) DINO

Backbone: Swin Transformer

Pretrained on COCO

Training strategy:

First trained on tooth detection (Subset 2)

Head replaced

Fine-tuned on disease dataset (Subset 3)

This transfer improves performance.

2) YOLOv8

Trained directly on Subset 3

Ensembling

At inference:

Weighted Boxes Fusion (WBF) applied

Combines DINO + YOLOv8 outputs

Done before label matching

6️⃣ Label Matching

For each detected diseased tooth:

Compute IOU with all detected tooth bounding boxes

Each enumeration ID receives vote weighted by IOU

Highest vote → chosen enumeration ID

Detection models assigned higher weights than segmentation outputs

7️⃣ Post-Processing

After label matching:

Convert enumeration IDs → FDI notation

Remove duplicate labels

Keep highest confidence

Apply prior knowledge filtering

Example: impacted teeth only 8th tooth in quadrant


8️⃣ Quantitative Results

| Model  | AR        | AP        | AP50      | AP75      |
| ------ | --------- | --------- | --------- | --------- |
| DINO   | 0.544     | 0.343     | 0.508     | 0.411     |
| YOLOv8 | 0.530     | 0.352     | 0.539     | 0.399     |
| Fused  | **0.592** | **0.371** | **0.543** | **0.447** |

9️⃣ Final Challenge Test Set Results (Table 2, page 7)

| Label Type  | AR    | AP    | AP50  | AP75  |
| ----------- | ----- | ----- | ----- | ----- |
| Quadrant    | 0.753 | 0.474 | 0.679 | 0.585 |
| Enumeration | 0.681 | 0.353 | 0.511 | 0.421 |
| Disease     | 0.592 | 0.371 | 0.543 | 0.447 |


🔟 Key Contributions

Hybrid segmentation + detection framework

Quadrant-wise segmentation improves tooth localization

DINO + YOLOv8 fusion improves disease detection

IOU-based voting for enumeration assignment

Use of prior dental knowledge in postprocessing

⚠ Limitations (Implicit from Results)

Enumeration AP relatively low (0.353)

Disease AP modest (0.371)

Heavy reliance on bounding box alignment

Multi-stage pipeline increases complexity

Segmentation accuracy not fully evaluated independently

📌 Final Summary

The paper proposes a modular integrated framework combining:

DINO

YOLOv8

U-Net

SE U-Net

DiffusionDet

Weighted Boxes Fusion

It achieves:

Disease AP = 0.371

Enumeration AP = 0.353

Quadrant AP = 0.474

on the Dentex Challenge test set.

6. 
A Deep Learning Approach to Teeth Segmentation and Orientation from Panoramic X-Rays”
Mou Deb, Madhab Deb, Mrinal Kanti Dhar

1️⃣ Objective of the Paper

This paper addresses two major tasks simultaneously:

Teeth Instance Segmentation

Teeth Orientation Estimation

It proposes a two-stage deep learning framework:

Stage 1 → Deep learning-based instance segmentation

Stage 2 → PCA-based oriented bounding box (OBB) estimation

Unlike previous works, this paper integrates segmentation + orientation in a unified framework.

2️⃣ Key Contributions

The authors claim the following major contributions:

Modified FUSegNet with grid-based attention gates

Introduced PCA-based OBB generation

Generated OBB coordinates for DNS dataset

Provided horizontal bounding box (HBB) + OBB + missing teeth detection

Achieved state-of-the-art IoU and DSC

Conducted detailed tooth-wise and categorical analysis

3️⃣ Dataset

Dataset used: DNS Dataset

Dataset Details (Table 1, Page 5)

Total images: 543

Resolution: 1991 × 1127

5-fold split:

Test: 111 images

Other folds: 108 each

Total teeth labels: 32 (FDI system)

Preprocessing

Image patching:

Patch size: 512 × 512

Overlap: 10 × 10

Stride: 502

Pixel normalization: [0, 1]

Each tooth assigned unique segmentation label (1–32)

4️⃣ Model Architecture

Modified FUSegNet architecture consisting of:

EfficientNet-B7 Encoder

Decoder

Grid-based Attention Gates (AG)

Parallel Spatial & Channel Squeeze-and-Excitation (P-scSE)

(Architecture shown in Figure 3, Page 5)

🔹 Encoder

Backbone: EfficientNet-B7

Pretrained on ImageNet

Compound scaling used (α=1.2, β=1.1, γ=1.15)

Suitable for 512×512 patches

🔹 Decoder

Upsampling + concatenation

Encoder features pass through Grid Attention Gate

Followed by:

P-scSE module

3×3 Conv + ReLU + BatchNorm

🔹 P-scSE Module

Parallel combination of:

Channel SE (cSE)

Spatial SE (sSE)

Addition + maxout

Improves:

Feature recalibration

Spatial + channel awareness

🔹 Grid-Based Attention Gate

Purpose:

Reduce false positives

Focus on small tooth structures

Weight skip connections spatially

Result:
~1.5% IoU improvement over original FUSegNet

5️⃣ Post-Processing

After segmentation:

If multiple regions of same label exist:

Three cases handled:

Case I:

If surrounded by background → remove region

Case II:

If background + single label → merge into label

Case III:

If adjacent to two labels → merge with most frequent border label

Improves:

IoU from 82.0 → 82.43

DSC from 90.1 → 90.37

6️⃣ Oriented Bounding Box (OBB) using PCA

This is the second stage.

Instead of training an OBB predictor, they use:

PCA-based Orientation Estimation
Why PCA?

No ground truth orientation available

Interpretable

Computationally efficient

Better than minAreaRect

OBB Generation Steps

Extract single tooth mask

Binarize

Apply PCA

Compute first principal component

Calculate angle:

If PCAangle < 0:

θ = 180 + (90 − PCAangle)

Else:

θ = (90 − PCAangle)

Rotate tooth

Compute horizontal bounding box

Rotate back

Final output:

Oriented bounding box

Rotation angle

7️⃣ Training Details

Optimizer: Adam

Learning rate: 0.001

Weight decay: 1e-5

50 epochs

LR reduced by 0.1 if no improvement for 10 epochs

Combined Loss: L=DiceLoss+FocalLoss

Dice loss → overlap awareness
Focal loss → handle class imbalance
