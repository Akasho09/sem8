> USED YOLO N COMPARED WITH U-NET .


## Dataset Details
> Total images: **32,585** panoramic radiographs
- Collected: 2014–2024
    - Single institution (Sivas Cumhuriyet University)
- Split:
    - Training: 24,577
    - Validation: 6,195
    - Testing: 1,813
- 28 tooth-implant region classes
- Third molars excluded
- Zygomatic implants excluded

📌 Dataset size is significantly larger than most previous implant studies.

### 🧠 3. Model Architecture
- Two Separate YOLOv8 Models
1. 1️⃣ Detection + Numbering Model
- YOLOv8 detection architecture
- Divides jaw into 28 regions
- Assigns FDI number
- Identifies implant presence in each region

2. 2️⃣ Implant Segmentation Model
- YOLOv8 segmentation version
- Pixel-level implant boundary detection

- 📌 Compared with:
    - Faster R-CNN
    - RetinaNet
    - DETR
    - U-Net
    - Mask R-CNN
    - DeepLab v3+
    - YOLOv8 outperformed all.
